# Frontend Review

Inspect:
- component boundaries
- state ownership
- server/client component boundaries when applicable
- unnecessary re-renders
- data fetching and waterfalls
- caching
- bundle and dependency cost
- accessibility
- forms and validation
- loading/error/empty states
- responsive behavior
- XSS and unsafe HTML
- SEO/metadata where relevant
- type safety

Prefer existing design-system and project patterns.

## Ngôn ngữ bắt buộc

- Phản hồi người dùng bằng tiếng Việt.
- Báo cáo, finding, explanation, plan và recommendation phải bằng tiếng Việt.
- Giữ nguyên technical terms phổ biến bằng English khi cần.
- Không dịch code, identifier, package name, API route, database name, CLI command, log hoặc error message.
