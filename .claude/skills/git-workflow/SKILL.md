# Git Workflow

Before changing git state:
- inspect status
- inspect diff
- inspect branch and recent history

Keep commits logically focused. Never commit secrets, generated junk, local environment files, credentials, or unrelated changes.

For conflict resolution, understand both sides and verify the resulting behavior; never resolve conflicts by blindly choosing one side.
