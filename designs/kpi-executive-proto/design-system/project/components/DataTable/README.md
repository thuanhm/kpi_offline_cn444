Bảng thay thế cho mọi biểu đồ (WCAG): tiêu đề cột dính, số căn phải.

**Hàm:** `VTB.dataTable(…)` trả về chuỗi HTML đã escape; nạp `tokens.css`, `components/bundle.css`, `components/bundle.js`.

**Bạn cung cấp:** Truyền `{caption,cols:[{k,t,cls,html}],rows}`. `rows[i]._key` đặt `data-key`.

**Quy tắc:**
- Mỗi biểu đồ phải có bản bảng; bảng chứa mọi giá trị biểu đồ thể hiện.
